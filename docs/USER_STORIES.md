# Agile User Stories

1. **As a CFO**, I want a dashboard of revenue, expenses and profit so I can understand business performance quickly.
2. **As a finance analyst**, I want to import ERP transactions from CSV so I can analyze new data without manual entry.
3. **As an auditor**, I want an audit trail so I can see who changed financial records.
4. **As a finance analyst**, I want unusual transactions flagged so I can investigate exceptions.
5. **As a CFO**, I want a revenue forecast so I can plan future periods.
6. **As an administrator**, I want role-based access so destructive operations are restricted.
7. **As an engineer**, I want CI to run tests on every PR so regressions are caught before merge.
